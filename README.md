# WD Lavagem

**Automotive Detailing & Car Wash Booking Website**

A web development project created to provide a modern online presence for an automotive detailing business, allowing customers to explore services and request appointments online.

## Overview

WD Lavagem is a website designed to simplify the appointment booking process for a car wash and automotive detailing business.

The project focuses on building a clean, responsive and user-friendly experience while integrating a database to manage services and appointments.

## Technologies

- HTML5
- CSS3
- JavaScript
- Supabase

## Features

- Responsive website layout
- Service presentation
- Online appointment booking interface
- Service selection
- Supabase database integration
- Appointment management dashboard (in development)
